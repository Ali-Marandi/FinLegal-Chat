# FinLegal-Chat

## AI-Powered Chatbot for Financial Legal Document Analysis

This project develops an AI-powered chatbot designed to assist with the analysis of financial legal documents. It leverages natural language processing (NLP) to understand complex legal texts, extract relevant financial information, and answer user queries, making legal document review more efficient and accessible.

### Features:
- NLP-driven extraction of key financial terms and clauses from legal documents.
- Interactive chatbot interface for querying document content.
- Summarization of lengthy legal sections.
- Identification of potential risks and opportunities within financial contracts.

### Technologies Used:
- Python
- NLTK / SpaCy (for NLP)
- Transformers (for language models)
- Flask (for web interface)

### Installation and Usage:

```bash
git clone https://github.com/Ali-Marandi/FinLegal-Chat.git
cd FinLegal-Chat
pip install -r requirements.txt
python finlegal_chat.py
```
